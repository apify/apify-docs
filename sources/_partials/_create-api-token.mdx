To get an API token, go to [**Settings > API & Integrations**](https://console.apify.com/settings/integrations) in Apify Console, select **Create a new token**, and enter a name. Keep the 90-day **Expiration** or change it, select **Create**, and copy the token. You can view the token only once, so store it somewhere safe, such as a password manager. If you lose it, [rotate the token](/account/api-tokens#rotation) or create a new one.
