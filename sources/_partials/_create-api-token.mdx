To get an API token, go to [**Settings > API & Integrations**](https://console.apify.com/settings/integrations) in Apify Console, select **Create a new token**, enter a description, select **Create**, and copy the token. You can view it only once, so store it somewhere safe, such as a password manager. If you lose it, [rotate the token](/integrations/api#rotation) or create a new one.
