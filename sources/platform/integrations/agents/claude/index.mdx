Apify integrates with [Anthropic Claude](https://www.anthropic.com/claude) in claude.ai and the Claude Code CLI (via the Apify plugin), and in the Claude Desktop app (via the Apify MCP server). Each gives Claude a way to call Apify Actors as tools and read their results.
