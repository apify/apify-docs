Apify integrates with two [Alibaba](https://www.alibabagroup.com) coding tools through a single Apify plugin: [Qoder](https://qoder.com), an agentic coding platform available as the Qoder CLI, IDE, Desktop app, and QoderWork, and [Qwen Code](https://github.com/QwenLM/qwen-code), an open-source terminal agent. Qwen Code installs Qoder plugins, so it reuses the same plugin with no separate build. Each gives the tool a way to call Apify Actors and read their results.
