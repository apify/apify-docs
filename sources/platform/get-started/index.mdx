Apify is a cloud platform for web scraping, data extraction, and automation. Everything on it revolves around _Actors_ - serverless programs that run in the cloud. You can run Actors that other people built, build your own, and connect either one to the rest of your stack. This page explains how the platform fits together and where to start.

## How Apify works

An Actor takes a structured input, does a job such as scraping a website, and stores its results on the platform. You can start it from Apify Console, the [API](/api/v2), or a [schedule](/actors/running/schedules). For the full model, see [Actors](/actors).

Because every Actor shares this input > run > output model, they compose. One Actor's output can feed another, results flow into [integrations](/integrations) like Make, Zapier, or n8n, and you can call any Actor from your code like a regular API.

Actors are the unit of work. The rest of the platform exists to run them, hold what they produce, and connect them to everything else, and each item in the top navigation covers one part. For how the platform is built, what happens during a run, and how workloads stay isolated, see [Platform architecture](/security/architecture).

## How Actors get to Apify Store

[Apify Store](https://apify.com/store) holds thousands of public Actors built by Apify and the community. Each one started as code that a developer wrote, deployed to the platform, and published - optionally setting a price, since Store Actors can [earn their developers money](/actors/publishing).

You can stand on either side of that exchange. Run other people's Actors to get data without writing code, or build your own - for yourself, your team, or as a product in Store.

## Run your first Actor

The quickest way to understand the platform is to run something. Open [Apify Store](https://apify.com/store), pick an Actor, select **Start**, and watch the results arrive. It needs no code.

## Pricing

Running Actors consumes platform usage, such as compute, storage, and proxy traffic. Some Store Actors charge per event instead, for example per result. Your plan sets your monthly usage, limits, and features. For the pricing models, see [Actors in Store](/actors/running/actors-in-store) and [Usage and resources](/actors/running/usage-and-resources). For your own account, see [Limits](/account/limits) and [plans](https://apify.com/pricing).

## Next steps

Pick the path that matches what you want to do. Each one walks you through the loop and points you to the right tutorials and concept pages in order:

- [Run Actors](/get-started/run-actors) - use existing Actors from Apify Store to get data or automate a task, no coding required.
- [Build Actors](/get-started/build-actors) - build, deploy, and publish your own Actor on the Apify platform.
- [Integrate Apify](/get-started/integrate) - call Actors from your code, react to runs with webhooks, and connect your workflow tools and data stores.
- [Connect an AI agent](/agents) - give an agent or coding assistant access to Actors.

To learn web scraping itself, see the free courses in [Apify Academy](/academy).
